# Matching Engine Architecture

## Overview

The Matching Engine is responsible for retrieving all users located inside the H3 cells generated by the Propagation Engine.

The Propagation Engine determines the search area by expanding from the starting H3 cell and returning the cells contained within a specific ring.

The Matching Engine uses these cells to find all users currently indexed inside them and returns the available candidate users with their information.

---

## Matching Flow

1. Receive Cells From Propagation Engine

The Matching Engine receives an array of H3 cells from the Propagation Engine.

Example:


[
"892b986616bffff",
"892b9866173ffff",
"892b9866177ffff"
]


Each cell represents an area that should be searched for nearby users.

---

2. Spatial User Lookup

The engine checks the user spatial index to find users stored inside each H3 cell.

Example:


H3 Cell
|
|
v

User Spatial Index

{
"892b986616bffff": [
User1,
User2
],


"892b9866173ffff": [
User3
]
}


---

3. Candidate Extraction

All users found inside the provided cells are extracted and combined into a single candidate list.

Example Output:


[
{
id:1,
name:"Liam",
latitude:43.945,
longitude:-78.896,
cell:"892b986616bffff"
},

{
id:2,
name:"Yahaya",
latitude:43.946,
longitude:-78.897,

cell:"892b9866173ffff"
}
]

## Responsibilities

The Matching Engine is responsible for:

- Receiving cells from the Propagation Engine
- Searching the user spatial index
- Extracting users inside those cells
- Combining users from multiple cells
- Returning candidate users for dispatch
